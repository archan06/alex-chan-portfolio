NFLillion

Retro NFL Trivia Game · 1,000+ daily players

A free NFL trivia game that over 1,000 people play every day: seven prompts, 25 seconds each, and the rarer your correct answer, the bigger the play. I wrote a Python pipeline that generates the 418 prompts and 18,000+ accepted answers from cited Wikipedia tables. The server owns the clock and the scoring, and player scores and stats are saved in the browser.

Built withNext.js · TypeScript · React · Tailwind CSS · SQLite · Fly.io

LIVE 3,108 users

Landed

Job Application Tracker

A full-stack job tracker with a drag-and-drop Kanban board and event-sourced status history. An MCP server with OAuth 2.1 lets Claude and ChatGPT read and update your applications, and the Claude API classifies forwarded job emails and updates applications automatically, with undo. Covered by unit, integration and Playwright end-to-end tests, with rate limiting and per-user data isolation.
